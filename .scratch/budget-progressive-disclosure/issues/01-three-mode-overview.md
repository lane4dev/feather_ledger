# 01 · 三态总览卡与共用展示规范

Triage: ready-for-agent

Blocked by: 无

关联规格见[预算页重构](../spec.md)。

## 交付结果

在现有预算首页切换月份，就能读到当月预计剩余、历史结余或超支、未来可自由支配金额。以总览卡为第一个使用方落实后续页面的展示约定。

## 范围与文件所有权

负责 BudgetOverviewCard、共用的预算 UI model 与 mapper，以及本轮所有页面需要的四份 ARB 文案和生成文件。提前提供分类行金额与风险、计划外占比、复盘摘要、趋势点与有效月判定所需的展示数据。保持现有调用方可用，首页重排归 06。仅在账本与预算确实共用时提取已有排版或材质，保留共享组件默认行为。

## 验收与测试

- [ ] 沿用 AppTheme、AppCard.overview、间距与排版令牌。主金额用 Text.rich 与等宽数字分别呈现符号、整数和小数；顶行标签、主金额、进度条、三栏底行按规格排列。固定／弹性拆解和全盘实耗旁注移出主卡。
- [ ] 跟踪态用主色微渐变、实际＋待入账双段条和今日刻度，胶囊显示「实耗达标 X/Y」；复盘态用低饱和色和纯实际单段条；规划态用 1 dp 虚线边框和固定基线占比。各态底行只汇总已设预算分类，切月约 250 ms 并尊重减少动画设置。
- [ ] 锁定规格算例：预算 ¥200、实际 ¥40、待入账 ¥30 时当月显示 ¥130；额外计划外支出不改变主金额。历史月结余 ¥160；未来月已设预算基线 ¥60 时可自由支配 ¥140。测试负值、无预算、零分母及进度封顶。
- [ ] 以固定时钟运行总览 Widget Tests 和 mapper 单测。浅色／深色分别在 400 × 700 dp、窄屏、大字号和宽屏检查金额、刻度与虚线，用定点 Golden 或可复现截图核对视觉。若提取账本组件，复跑账本页头测试。
- [ ] 复用已有本地化键，新增文案覆盖 en、zh、zh_Hans、zh_Hant，基础中文与简体同步。运行 flutter gen-l10n，后续票消费生成的接口。
