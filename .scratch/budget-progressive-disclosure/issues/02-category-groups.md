## 验收与测试

- [ ] 沿用领域排序，将已设预算行放入一张 AppCard.group，用分隔线分行、40 dp 圆形色调图标及 4 dp 进度条。名称旁的异常标记具有可朗读语义，具体波动比例留给 L3。
- [ ] 当月预算 ¥200、实耗 ¥180、待入账 ¥40，行内显示「预计超支 ¥20」「含待入账 ¥40」；实耗 ¥220 且无待入账时显示「已超支 ¥20」。历史月实际 ¥40 时左侧写「已用 20%」，右侧写「结余 ¥160」和「¥40 / ¥200」。
- [ ] 规划行给出固定基线和可用的近三月均值，省去全零消耗与空进度条，点击可编辑行发起编辑。跟踪和复盘行保留详情操作。历史归档分类保持可读。
- [ ] 计划外分组包含有实际或有效待入账的未设预算分类。有实耗时标题为「已消费 ¥X」，只有待入账时为「待入账 ¥Y」。以未取整的实际占全盘实际比值判断 ≥5%，第四个及以后的达线分类同样有标注。零分母省略占比；可编辑行提供低权重「设预算」。
- [ ] Widget Tests 覆盖上述三态、仅待入账、混合、空组、恰好 5% 与略低于 5%，并操作行与按钮。浅色／深色分别在 400 × 700 dp、窄屏、大字号及宽屏检查长名称、大金额的换行与点击区域，金额和名称完整可读。
