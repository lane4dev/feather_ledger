# 06 · L1 首页编排与跨页导航

Triage: ready-for-agent

Blocked by: 02, 03

关联规格见[预算页重构](../spec.md)。

## 交付结果

从预算 Tab 切换月份、读分类清单、进入复盘或编辑，再返回原来的月份与滚动位置。

## 范围与文件所有权

负责 BudgetScreen、首页视图状态、原有月份控件和「+」选择器的接线，必要时调整预算路由。消费 01–03 的组件，调用既有分类详情入口，可与 05 并行。维护真实首页入口 Widget Tests，替换已被规格取代的旧交互断言。

## 验收与测试

- [ ] 当月按总览、已设预算、计划外、紧凑复盘入口排序。入口使用 LucideIcons.barChart2 与单行摘要。历史月的唯一复盘入口位于主卡下，优先展示超支榜首，否则取结余榜首，并提供可用的短备忘预览；无归因、无备忘仍可打开 L2。
- [ ] 未来月用单行规划提示替换复盘入口，只有能确认沿用时才写「沿用上月规则」，保留适用的已物化账单提示。未来可编辑分类直接打开 BudgetEditSheet；当月和历史分类进 L3。零活动可编辑分类收进「+」。保留无账户管理入口、无预算首设和有活动时的计划外清单。
- [ ] 保留左右箭头、横滑、年月选择器和跨年切换。L1 → L2 → L3 逐级返回，来源月份、币种、滚动位置正确；从首页分类与计划外分组直接进 L3 后也能原路返回。首页底部至少 88 dp，最后操作可滚至导航栏上方。
- [ ] 以固定时钟、替身 BudgetService 和真实视图模型运行 Widget Tests，验证三态顺序、入口数量、点击目标、箭头／系统返回和空态。浅色／深色在 400 × 700 dp 默认字号、至少四个普通分类时看全总览及至少三行；窄屏、大字号及宽屏检查完整文字和底部可点区域。
