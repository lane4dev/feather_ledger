# 预算页重构 · 跟踪、复盘与规划

Triage: ready-for-agent

## Problem Statement

打开当月预算时，我先看到总预算、全盘实耗说明和六个月趋势，还要往下滚才能找到关心的分类。总预算只覆盖已设预算分类，紧邻它的支出说明却涵盖所有分类，很容易把两者当作同一范围。分类行把金额、固定与弹性拆解、异常百分比并排摆放，小屏上连分类名都可能读不全。到了下月，我最常做的事是调预算，还要先经过一张没有消费记录的详情页。

## Solution

首页（L1）回答所选月份最重要的一个问题：当月还能用多少、过去一个月结余或超支多少、未来一个月扣除固定账单后可支配多少。总览之后尽快展示分类进度和计划外支出。需要理解整月结果时进入「月度复盘与趋势」（L2）；需要追查某一分类时进入该分类的完整详情页（L3）。规划月份的可编辑分类直接进入预算编辑。

## User Stories

1. 作为每天查看预算的人，我希望打开当月就看到预计剩余和至少三个完整分类，以便不滚动也能决定今天的消费。
2. 作为有待入账账单的人，我希望看到实耗、待入账分别占用了多少预算，以及今天在本月的位置，以便判断消费进度。
3. 作为只给部分类别设预算的人，我希望主卡上的支出、进度和达标数都对应已设预算分类，以便核对数字。
4. 作为切回上月的人，我希望看到按实际消费结算的结余或超支，以便了解最终结果。
5. 作为做月末复盘的人，我希望从主卡下方看到影响最大的分类和已写的备忘，以便决定是否打开完整复盘。
6. 作为规划下月的人，我希望看到固定基线和剩下的可支配额度，以便给弹性支出留出空间。
7. 作为调整计划的人，我希望点分类就能编辑预算，并能参考已有固定账单和近期均值，以便一次完成调整。
8. 作为浏览分类的人，我希望完整读到分类名、剩余额度和实际对预算的金额，以便辨认名称相近或金额较大的分类。
9. 作为发现异常的人，我希望首页有轻量提示，点开才看到与近三个月均值的具体差异，以便理解波动原因。
10. 作为有计划外支出的人，我希望在同一个分组看清金额、较大支出占比和设预算入口，以便补上漏设的预算。
11. 作为只有待入账账单的人，我希望相应分类也能出现在计划外支出中，并标明待入账，以便提前安排。
12. 作为新增预算的人，我希望从右上角找到尚无支出的分类，以便给它设预算。
13. 作为分析整月支出的人，我希望比较固定实耗、弹性实耗、固定基线及超支和结余的前三项，以便找到下月可以调整的类别。
14. 作为积累了几个月记录的人，我希望在整月和单分类两个范围查看六个月趋势，以便区分持续变化与偶发支出。
15. 作为刚开始记账的人，我希望历史不足时能直接读到下一项内容，以便把屏幕空间留给已有数据。
16. 作为核对分类的人，我希望从贡献最大的三笔流水进入相应的编辑表单，并能查看其余流水，以便纠正源记录。
17. 作为写复盘备忘的人，我希望月度与分类备忘分别保存、重新打开仍可读取，以便以后理解当时的决定。
18. 作为使用深色模式、较大字号或不同语言的人，我希望仍能认出当前月份的用途、完整读出金额并点到最后一项操作。

## Implementation Decisions

### L1 首页

保留月份前后箭头、横滑与年月选择器。三态以所选月与预算时钟所在本地年月比较，沿用月度摘要的模式。跨年也遵循同一比较。L1 使用同一套极简 Material 3 布局，各模式只出现一个复盘入口或规划提示。

| | 当月 · 跟踪 | 历史月 · 复盘 | 未来月 · 规划 |
| --- | --- | --- | --- |
| 顺序 | 总览 → 已设预算分类 → 计划外支出 → 月度复盘与趋势 | 总览 → 紧凑复盘摘要 → 已设预算分类 → 计划外支出 | 总览 → 已设预算分类 → 计划外支出 → 单行规划提示 |
| 顶行与材质 | 主指标标签、右侧「实耗达标 X/Y」胶囊；主色微渐变，隐藏「跟踪」徽标 | 「复盘」，低饱和中性灰或微靛蓝 | 「规划」，浅色调渐变与 1 dp 虚线描边 |
| 主金额 | 本月预计剩余 = 总预算 − 已消费 − 待入账；小于零标明预计超支 | 本月结余或本月超支 = 总预算与实际支出的差额，以标签说明方向 | 可自由支配 = 总预算 − 已设预算分类固定基线；基线超过预算时显示真实缺口 |
| 圆角进度条 | 实色实际支出、浅紫待入账、今日日期刻度 | 单段实际支出 | 仅用浅紫或斜纹画固定基线占比 |
| 卡底三栏 | 已消费、待入账、总预算 | 已消费、预算使用率、总预算 | 固定基线、基线占比、总预算 |
| 分类行 | 有待入账优先写「含待入账 ¥30」，否则写「已用 20%」。右侧显示剩余；仅计入待入账后超额时标「预计超支」，实际已超额时标「已超支」。次行显示实际 / 预算；点行进 L3 | 左侧副标题显示「已用 N%」（实际 / 预算）；右侧主行显示「结余 ¥X」或「超支 ¥X」，次行显示实际 / 预算；点行进复盘视角 L3 | 副标题给出固定基线与可用的近三月均值。右侧突出规划额度，有信息的参考值才显示。省去全零消耗和空进度条；点行直接开预算编辑 |

- **总览卡**仅保留顶行、主金额、进度条和三栏底行。沿用账本微渐变与金额字阶，用 `Text.rich` 将符号、整数、小数排成一个可读金额，数字启用 `FontFeature.tabularFigures()`。卡内所有金额、比例与达标计数只涉及已设预算分类。达标数沿用既有实际达标定义。零预算时沿用空态与无分母占位。图形填充封顶，超支金额照实显示。切月以 `AnimatedContainer` 和 `AnimatedSwitcher` 在约 250 ms 内过渡材质与内容，遵循系统减少动画设置。
- **已设预算分类**采用 A 分组清单：所有行放在同一张卡内，用分隔线分行，沿用现有排序。每行只有 40 dp 圆形色调图标、中间双行文本、右侧双行金额和底部 4 dp 细进度条四个锚点。异常标记紧邻名称，以轻量琥珀色点或趋势微图标提示，提供可朗读的异常语义。窄屏、长名称或大字号可换行、增高或重排文本组，名称与金额完整可读；禁止省略号、裁切及靠叠加固定/弹性标签传达信息。
- **计划外支出**只收纳所选月有实际或有效待入账的未设预算分类。分组有实耗时，标题右侧显示「已消费 ¥X」，X 为该组实际小计；全组仅有待入账时显示「待入账 ¥Y」，Y 为该组待入账合计。有实耗也有待入账时，各行另标各自的待入账。实际占比 = 分类实际 / 全部分类实际；用未取整的比值判定 ≥ 5%，再格式化「占本月总支出 N%」。适用于所有达线行，包括排行第四及以后；零分母省略占比。右侧给出金额和低权重「设预算」；仅有待入账时明确标出金额性质。有历史的归档行可读，编辑权限沿用既有规则。组为空则收起。此组独占未设预算的逐项展示和大额提示。
- **复盘入口与规划提示**。当月在列表底部放一张使用 `LucideIcons.barChart2` 的「月度复盘与趋势」入口卡，摘要一行显示固定与弹性实耗或简短备忘。历史月将唯一入口移到总览正下方，优先显示超支榜首，否则取结余榜首，附短备忘预览；缺少归因或备忘时仍可打开 L2。预览放不下时用较短的完整摘要，正文留在 L2。规划月原入口位置显示一行固定账单提示；只有已知沿用规则时才写「沿用上月规则」。移除当月展开式复盘预览和相应浮动切换栏。
- **无活动分类与空态**。未设预算且实际、待入账均为零的可编辑分类统一进右上角「+」分类选择抽屉。无预算仍可设首个预算，有活动仍展示计划外支出。保留无账户时的管理入口。首页滚动内容底部预留至少 88 dp，最后一项可滚至导航栏上方并点击。

### L2 月度复盘与趋势

- L2 使用独立完整页面 `BudgetReviewScreen`。当月的列表底部入口卡和历史月的复盘摘要条都打开此页，并带入所选月份与币种。页面标题为「月度复盘与趋势」。点标题栏返回箭头或使用系统返回，回到预算首页原先的月份和滚动位置。
- 固定实耗、弹性实耗和固定基线按**整月全盘**展示，并明确该范围。固定基线包含固定实耗和有效待入账，属于参考量，三项不可相加成支出。历史月有遗留账单时，在这里解释其未计入结余。高频或远期排期的既有物化范围提示仍在涉及待入账的详情或规划提示处可见。
- 并列呈现超支 TOP 3 与结余 TOP 3，直接使用领域已排序的预算差额结果。点分类进入同月 L3。六个月趋势的图例写「全部实际支出」（柱）和「已设预算总额」（线）。月度实际柱统一使用主色，即使柱高于线也保持主色：柱包含计划外支出。保留已有月份备忘标记。月度备忘可编辑、保存最多 500 字，清空沿用现有删除语义。保存失败用本地化提示并保留输入。

### L3 分类详情页

- 使用独立完整页面 `BudgetCategoryDetailScreen`。从首页分类行、计划外支出分类或月度复盘归因项进入时，带入所选分类、月份与币种。标题栏显示分类名称和返回箭头；使用标题栏或系统返回时回到进入前的页面及滚动位置。顶部展示紧凑进度。可编辑分类的标题栏右上角提供「⋯」菜单，依次列出「编辑」和「删除」。「编辑」打开该分类的预算编辑表单。「删除」默认选中「仅本月」。确认时同时移除该预算额度和对应的分类复盘备忘，并在确认文案中明示。分类、流水、整月备忘及其他分类或币种的备忘均保留。若主动选择「本月及以后」且存在后续预算规则，确认按钮上方提示「此操作也会清除之后已设置的预算」。两种范围均只作用于当前币种和所选分类。「仅本月」清除所选月额度和该月分类备忘。「本月及以后」从所选月起清除额度和所有对应分类备忘，涵盖没有单设预算规则的月份。确认文案始终写明备忘范围，例如「将删除 11 月及以后的旅行预算和分类备忘」。未设预算时「删除」置灰，归档分类只读并隐藏菜单。发生异常时展开具体比较，如「较近 3 月均值 +300%」。随后展示固定实耗、弹性实耗、待入账构成；历史复盘只按实际构成。保留固定基线、上月实际和可用的近三月均值参考。
- 近六个月分类图沿用分类自身的预算、实际和可用的均值参考。仅当某月设有该分类预算且该分类实际支出严格超过该额度时，该月实际柱使用超支色。TOP 3 贡献流水沿用原排序，点击已入账交易或待入账账单分别打开对应编辑表单；超过三笔保留「查看全部」，返回后保留未保存的分类备忘。分类备忘沿用 500 字上限、按币种/月/分类保存与归档只读规则。
- **趋势显隐**由月度和分类各自的六个趋势点判定。窗口截至所选月，已到达的月份中，有有效预算或非零实际即算一月；只有备忘标记或补齐的空月份不计。少于两月时连同标题、图例、容器及其间距一起省去。月度图可见不代表每个分类图都可见。

### 表现层与文案

- 首页、复盘和下钻消费现有月度摘要。金额格式、显示用比例、基线的已设预算分类小计和趋势显隐由表现层模型或 mapper 提供；组件只负责布局和交互。保留整数金额、当前币种、归档可读性、预算编辑作用域及历史编辑确认。规则依据 ADR-0004、ADR-0006 和 Budget & Review 术语表。
- 使用账本已有的 Material 3 明暗主题角色、间距、金额排版、设计系统组件与 Lucide 图标。所有用户文案覆盖 en、zh、zh_Hans、zh_Hant，zh 回退内容同步简体。使用「计划外支出」等可直接理解的名称，禁止数据库式标题和闪光图标。

## Testing Decisions

- 分别点击当月入口卡与历史月摘要条，验证打开完整复盘页，显示对应月份与币种的数据。分别从首页分类行、计划外支出分类和复盘归因项进入 L3 完整分类页，核对标题、月份与币种。分别用标题栏箭头和系统返回，验证回到对应来源页时保留原月份与滚动位置。
- 用户已确认以现有 `BudgetScreen` 组件测试为主入口。沿用注入的时钟、按月返回摘要的替身 `BudgetService`、真实预算视图模型和 mapper，从月切换器、分类行、「+」和复盘入口发起操作。断言用户看到的金额、可见性、顺序、目标表单及保存后结果；避免绑定私有组件树。用现有 mapper 和抽屉测试补齐展示边界，用真实内存数据库的 BudgetDao 测试验证范围隔离与事务回滚。
- **三态算例**：已设预算 ¥200、实际 ¥40、待入账 ¥30，当月主金额为 ¥130。另加未设预算实际 ¥200 后主金额仍为 ¥130，计划外占比为 200/240，显示 83%。历史月同预算、同实际且有遗留账单时显示结余 ¥160。未来月已设预算基线 ¥60、另有未设预算基线 ¥20 时，可自由支配为 ¥140。再覆盖超支与无预算两种边界。
- **分类行与计划外分组验收**：当月仅一个预算 ¥200 的分类，实际 ¥180、待入账 ¥40 时，主卡显示「实耗达标 1/1」，分类行显示「预计超支 ¥20」及「含待入账 ¥40」。实际已消费 ¥220、无待入账时，显示「实耗达标 0/1」及「已超支 ¥20」。历史月实际 ¥40、预算 ¥200 时，左侧显示「已用 20%」，右侧主行显示「结余 ¥160」，次行显示「¥40 / ¥200」。计划外仅有待入账 ¥60 时标题显示「待入账 ¥60」；再增加计划外实际 ¥10 后标题改为「已消费 ¥10」，原行仍标待入账。
- **导航与去重**：用前后箭头走过三态，核对徽标、卡片色调、条形与日期刻度、分类副标题、L2 的位置和 L3/编辑分流。覆盖恰好 5%、略低于 5%、仅待入账以及四个以上分类达线；核对 L1 只有一个计划外支出分组、L2 没有第二张计划外榜单。未设预算零支出分类可由「+」设预算。
- **趋势图口径**：仅餐饮设预算 ¥200，餐饮实际 ¥40，另有计划外医疗实际 ¥200。L2 实际柱 ¥240 用主色，预算线为 ¥200；餐饮 L3 实际柱 ¥40 用主色。餐饮实际增至 ¥201 时，其 L3 柱使用超支色。
- **删除验收**：默认「仅本月」。取消后额度和分类备忘均保留；确认后重新打开，额度、关联分类备忘及其趋势图备忘标记均已清除。整月备忘、其他分类与币种不受影响。以 10、11、12 月均有旅行分类备忘为例，从 11 月删「仅本月」后，10 月和 12 月的备忘可读，12 月原有额度继续生效。另从相同初始状态删「本月及以后」，10 月保留，11 月及以后该币种的旅行分类备忘全部清除，包含没有独立预算断点的月份。有未来预算规则时另出现覆盖提示。在 DAO 测试中令备忘删除失败，验证整笔删除回滚，原额度、后续规则和备忘均能读回。
- **深层行为**：月度和单分类分别造出 0、1、2 个有效月，验证图表阈值和隐藏时的布局。从详情页右上角菜单验证编辑、取消删除、按两个作用域确认删除，以及未设预算和归档时的操作权限。核对异常详情、归因和贡献流水跳转，验证月度/分类备忘分别保存、500 字可保存、501 字不能写入，归档分类只读。既有抽屉测试提供查看全部后保留草稿和历史编辑确认的先例。
- **可读性**：使用既有 400 × 700 dp 手机测试视口、默认字号、至少四个有预算的普通名称分类，首屏完整显示总览和至少三行，空间足够时显示第四行。另以窄屏、长名称、大金额与放大字号检查重排、完整文本和底部可点击性。覆盖浅色、深色及英文、简体、繁体。以实际画面或截图和可点击区域核对首屏、虚线、刻度和裁切，单纯找到文本节点不足以证明可读。
- **回归门槛**：更新原先断言「全盘实耗旁注」「展开复盘工具栏」的页面测试以匹配新交互。实现后运行 `flutter gen-l10n`、`flutter analyze`，确保零新增 warning/error；运行全部既有预算单元测试（含 DAO、计算器、服务、备份、视图模型和 mapper）及相关预算页面、抽屉、交易表单提示组件测试。

## Out of Scope
