# 02 · 全应用只读金额采用紧凑格式

Triage: ready-for-agent

Blocked by: 无

关联规格见[账本页 UI 重构](../spec.md)。

## 交付结果

用户在账本、搜索、交易详情、账户管理、预算和报表中看到一致的金额符号顺序。

## 范围与文件所有权

负责现有金额格式器、表现层模型和仍在拼接符号的展示入口。先完成 TransactionTile 的金额迁移，交由 04 改行布局。复用账本金额单位及各页面已有的符号语义，在映射或格式化处生成展示字符串。可编辑金额框、CSV、备份继续使用原有契约。

## 验收与测试

- [ ] 同一笔支出在流水、搜索结果和详情中均显示 `-¥10.00`；另测收入 `+¥10.00`、透支余额 `-¥12.34`、无方向转账 `¥20.00` 和标签承载方向的「支出 ¥10.00」。无符号金额开头无空格。
- [ ] 沿用所属币种、两位小数与原始整数。混合币种账户列表保留 ISO 后缀，例如 `-¥12.34 JPY`。预算和报表按各自口径显示金额。
- [ ] 扩展格式化单测、搜索与凭证一致性 Widget Tests，并覆盖账户、预算和报表的代表性金额。复用输入边界测试检查负数和未完成的小数文本仍可编辑。
- [ ] 在浅色、暗色及 360 dp、800 dp 宽度检查只读金额与币种完整可读。
