# 04 · 粘性日期列、同日卡片与双行流水

Triage: ready-for-agent

Blocked by: 01, 02

关联规格见[账本页 UI 重构](../spec.md)。

## 交付结果

连续滚动时可凭左栏日期定位交易，在右侧同日卡中比较金额、识别预约状态并打开相应详情。

## 范围与文件所有权

负责 LedgerTimeline、TimeAnchor、TransactionTile 及相关账本局部样式。沿用 LedgerDaySection 的吸附与惰性构建机制，复用 CategoryIcon、02 提供的只读金额和 LedgerDayGroup 的收支小计。在按日时间线内部完成布局，避免与 03、05 同时修改页面和列表外壳。

## 验收与测试

- [ ] 日期列固定 52–56 dp，与首条流水同顶；向前或反向滚动，前后日期在工具栏下沿连续交接。仅本地今天显示 primaryContainer 圆形徽章，星期用 onSurfaceVariant。相邻日卡间距 12–16 dp。
- [ ] 每个日期一张 surfaceContainerLow 卡，圆角 16–18 dp。默认字号行高 60–68 dp，分类圆标 36–40 dp，金额等宽且右对齐。第一行有备注显示备注，否则显示分类名，第二行显示账户。沿用写入时分类快照、转账的双方账户及无分类余额用途。
- [ ] 待入账使用细描边时钟胶囊，标题保持可读。失败、已跳过和已入账有可辨认状态，保留各自详情操作与日期栏所在行的点击行为。去掉行内分类文字胶囊。
- [ ] 只在可见记录至少两笔且存在可计收支时显示带细分隔线的小计。测试单笔、全待入账、「已支出 ¥10 + 待支出 ¥20」以及含转账、余额用途、排除合计账户的日期。混合示例只汇总「支出 ¥10.00」，无小计时连同留白一起省略。
- [ ] 扩展时间线和待入账 Widget Tests，检查日期吸附、边界交接、行点击、今天标记及两行标题。以 360 dp、800 dp 检查浅色、暗色与动态色；在窄屏放大字号，长账户名可省略并在详情读全，金额和状态完整可见，胶囊可换行。
