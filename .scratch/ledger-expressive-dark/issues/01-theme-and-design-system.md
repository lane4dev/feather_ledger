# 01 · 全应用 M3 主题与设计系统

Triage: ready-for-agent

Blocked by: 无

关联规格见[账本页 UI 重构](../spec.md)。

## 交付结果

账本、预算、更多及其子页采用同一套浅色、暗色与系统动态色。沿用现有主题偏好和 Material 3 组件入口。

## 范围与文件所有权

负责应用主题装配、AppTheme、语义色和后续票所需的共享组件变体。复用 AppCard、AppBadge、AppIconButton 与 AppTypography。用可选样式支持概览和日卡的不同表面、圆角以及状态胶囊的细描边；普通卡片继续使用原有尺寸。由本票集中维护共享设计系统。

## 验收与测试

- [ ] 按规格实现四层默认色。依次按页面、日卡、底栏和概览检查，浅色为 `#F7FAF7 / #EFF4EF / #E6EDE7 / #DFE6E1`，暗色为 `#111413 / #191D1B / #1B201E / #222826`。
- [ ] 切换浅色、暗色和跟随系统时采用对应亮度。动态色可用时表面、今日徽章、FAB 与导航指示器取系统角色，缺失或读取失败时回落到相应默认色。收支保留语义色相，自选分类保留用户选色。
- [ ] 用设计系统 Widget Tests 注入两种默认和两种动态配色，检查实际叠色后的前景与背景。普通文本至少 4.5∶1，大文本与识别控件或状态所需的图形至少 3∶1。验证 24 dp 概览圆角、16–18 dp 日卡圆角、48 dp 图标按钮热区及等宽金额排版。
- [ ] 在 360 dp 和 800 dp 宽度通过真实路由切换账本、预算、更多，检查三页主题角色及既有布局、导航行为。
