## 交付结果

## 范围与文件所有权

清理经调用点核实已无用途的旧样式、分类文字胶囊、整行透明度分支与旧测试断言。保留其他页面仍在使用的共享组件。复用现有真实路由和 Riverpod 测试配置，集中验证跨模块行为。

## 验收与测试

- [ ] 在真实路由中覆盖切月、日期吸附和点击、搜索、详情、待入账操作、概览显隐及报表往返。核对返回位置、金额符号、日小计和月收支。经底栏进入预算、更多，再从更多打开设置，确认备份与恢复入口可达。
- [ ] 使用同一组数据在默认浅色、动态浅色、默认暗色、动态暗色下检查四层表面、文本及状态对比度。在 360 dp 与 800 dp 下检查页头热区、日卡、底栏与 FAB，复测窄屏大字号的长账户名、失败状态和最后一笔金额。
- [ ] 运行各模块 Widget Tests、完整 flutter test 和 flutter analyze。以行为断言、实测布局边界与前景背景对比度核对规格；沿用现有页面测试方案。
- [ ] 确认事件、投影、业务计算、导航目的地、可编辑金额和导出备份的数据契约仍通过既有回归测试。清理前核对调用点，避免删除其他页面依赖的样式。
