# 03 · 紧凑月份工具栏与资产概览卡

Triage: ready-for-agent

Blocked by: 01

关联规格见[账本页 UI 重构](../spec.md)。

## 交付结果

用户能切月、搜索、显隐概览金额，并从资产概览进入所选月报表，再回到原浏览位置。

## 范围与文件所有权

负责 LedgerAppBarTitle、LedgerHeader 及 LedgerScreen、LedgerTransactionList 的页头接线。维护本次新增的四份 ARB 文案并运行本地化生成。共享组件和金额字符串分别由 01、02 维护。

## 验收与测试

- [ ] 月份与两箭头组成紧凑居中组合，工具栏右侧仅有搜索。所有图标按钮至少 48 × 48 dp，眼睛图形为 18–20 dp。保留箭头切月、点选月份、左右滑月、折叠显示月份与余额、点折叠栏回顶。
- [ ] 概览使用 surfaceContainerHigh 和 24 dp 圆角，主金额用粗体等宽数字。月收支子容器扣除中缝后各占 50%，两列统一左对齐，月份标签与语义圆标清晰可读。切月时实时全部余额沿用当前账本币种及账户合计口径。
- [ ] 眼睛紧邻「全部余额」，提示和无障碍标签随状态切换。隐藏时覆盖概览三个数字及折叠余额，流水金额和日小计仍可读。点击概览其余跳转区域按现有路由打开所选月报表。
- [ ] 扩展页头和切月 Widget Tests，分别点击眼睛、报表箭头和搜索，覆盖切月加载以及报表往返。在浅色、暗色和 360 dp、800 dp 下核对热区、对齐与遮罩。检查英文、简体、繁体，基础中文回退与简体同步。
