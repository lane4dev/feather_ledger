# 月度复盘视角、偏差归因与 Review Note 机制

Type: grilling
Label: wayfinder:grilling
Status: resolved
Triage: ready-for-human
Blocked by: 01, 02

## Question

作为应用核心的「复盘（Review）」体验具体由哪些维度构成？历史月与当月如何区分展示，TOP 偏差归因、异常波动判断以及轻量 Review Note 的作用域与生命周期如何设计？

## Context

定位升级后（Q1: A, Q4: A）：
- 预算不仅用于当月控费，更核心的价值在于**月末与跨月复盘**；
- 确定纳入：历史月复盘视图（达标概况、TOP 超支/结余归因、主要贡献流水、相对近 3 月均值波动）、近 6 个月预算 vs 实际趋势对比、固定 vs 弹性支出拆解、以及轻量 `Review Note`（持久化并随 `.flbackup` 备份）。

本票需要锁定以下复盘产品规则：
1. **「跟踪模式」vs「复盘模式」的触发与切换**：
   - **已结束历史月份（`< 当前自然月`）**：默认进入「复盘视角」（还是保留标准进度列表并把复盘摘要卡置于顶部）？
   - **当前自然月**：默认处于「跟踪视角」（突出剩余可用、双段进度条与待入账），是否允许用户通过一个轻切换（或月末最后几天提示）预览本月实时复盘？
2. **偏差归因与异常波动判定标准**：
   - **TOP 归因范围**：复盘摘要重点列出 TOP N（如超支 Top 3 + 结余 Top 3 还是按偏差绝对值排序）？对某超支分类点击/展开时，如何挑选「主要贡献流水」（例如单笔金额占该类支出最高的前 3 笔，还是超出固定周期之外的 Top 弹性消费）？
   - **异常波动高亮阈值**：相对「近 3 月均值」涨幅达到多少时打上异常波动标签（例如 `>= +20%` 且绝对差额超过一定阈值，还是仅在超出预算且高于近 3 月均值时提示）？
   - **固定 vs 弹性洞察**：复盘里如何一句话/一行指标呈现（例如「本月超支 ¥600，其中 85% 来自弹性日常消费」或「固定周期占比 62%」）？
3. **跨月趋势窗口**：
   - 趋势图默认覆盖近 **6 个月**（`[M-5 .. M]`），是否允许左右切换月份联动刷新窗口？若某历史月份当时未设预算，趋势图上该月预算线是显示为 `0` 还是断点/虚线（无预算）？
4. **轻量 Review Note（复盘备忘）作用域与规则**：
   - Review Note 挂在 **月度维度** `(currencyCode, year, month)`，还是同时支持 **分类维度** `(currencyCode, year, month, categoryId?)`（月度总复盘一条 + 重点超支分类可选一条）？
   - Review Note 是否严格按 `Current currency` 隔离？长度上限、纯文本限制，以及在近 6 个月趋势柱状图上是否用一个极轻的小标记（点击悬浮可见备注摘要）提示「该月有复盘备忘」？

## Answer

经两轮决策，本票锁定以下月度复盘视角、偏差归因与 `Review Note` 机制：

1. **三态自适应视角（「规划 / 跟踪 / 复盘」）**：
   - **历史月（`< 当前自然月`）**：默认进入**复盘视角**（顶部展示达标分类数、固定 vs 弹性占比、TOP 超支/结余归因、近 6 月趋势与 Review Note；下方保留分类执行明细供下钻，不展示“本月还剩多少可用”等当月跟踪文案）。
   - **当前月（`== 当前自然月`）**：默认进入**跟踪视角**（突出双段进度条、剩余可用与待入账占额）；同时顶部提供轻量的 **「跟踪 / 复盘」切换**，支持随时预览当月实时复盘与记录备忘。
   - **未来月（`> 当前自然月`）**：呈现**规划视角**（突出预算额度与已排期周期底线 `Pending` 对比），不主动铺陈复盘区与 Review Note。
   - **历史月遗留待入账处理**：历史月复盘的达标判定、TOP 归因与 6 月趋势严格基于真实已入账 `Actual` 计算；若该历史月仍残留未处理的 `scheduled` / `failed` 账单，页面给出轻提示（笔数与金额），支持点击查看并补入账或跳过。

2. **偏差归因、未设预算预警与异常波动判定**：
   - **月度复盘摘要归因**：分栏展示 **超支 Top 3**（按 `Actual - Budget` 降序）与 **结余 Top 3**（按 `Budget - Actual` 降序）。另展示 **未设预算支出预警**（仅取未设预算分类中金额 Top 3 且占全月总支出 `>= 5%` 的分类，小额长尾消费留在下方未设预算分组中，避免噪音）。
   - **分类下钻「主要贡献流水」**：按单笔金额降序展示该月该分类 **Top 3 已入账支出**，每笔显式标注「固定/计划（`sourceScheduledBillId != null`）」或「弹性消费」。
   - **异常波动高亮（多币种量纲无关）**：当分类存在有效的 `3-Month Avg > 0`，且同时满足 **① 本月 `Actual` 较近 3 月均值涨幅 `>= +25%`** 与 **② 本月该分类支出占全月总支出 `>= 5%`（或该分类已超预算）** 时，打上「较均值明显上升」标识。
   - **固定 vs 弹性洞察**：复盘摘要呈现本月总实际支出中「固定周期/计划（Committed Actual）」与「弹性消费（Discretionary Actual）」的金额与占比拆解。

3. **分类列表默认排序**：
   - **跟踪视角**（已设预算组）：按「风险与消耗率降序」排列（已超支 → 有待入账风险 `At Risk` → 消耗率由高到低）。
   - **复盘视角**（已设预算组）：按「偏离焦点降序」排列（超支分类按超支额 `Actual - Budget` 降序排前，达标分类按实际支出 `Actual` 降序紧随其后）。
   - 「未设预算但有发生额」分组保持按发生额降序。

4. **近 6 个月趋势对比窗口**：
   - 窗口随 `FeatherMonthPicker` 选中月份 `M` 动态滑动展示 `[M-5 .. M]`。
   - 历史无预算月份仅绘制实际支出柱，预算折线在该月留空断点（不画成 `0`），并支持点击月柱查看该月复盘摘要与备忘。

5. **轻量 `Review Note` 作用域与生命周期**：
   - 作用域为 `(currencyCode, year, month, categoryId?)`：`categoryId == null` 为月度总复盘备忘，`categoryId != null` 为单分类偏离原因备忘；严格按 `Current currency` 隔离。
   - 形态为轻量化纯文本（上限 500 字，清空保存即删除该记录）；仅在历史月复盘视图与当月复盘预览中展示并允许编辑。
   - 已归档分类在历史月份已记录的分类 Review Note 保持只读保留供回溯，不随归档被删除。
   - 近 6 个月趋势图对写有月度 Review Note 的月份打极轻角标提示，方便跨月回溯原因。
