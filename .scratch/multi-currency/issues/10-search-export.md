# 搜索与导出的币种范围
Type: grilling
Label: wayfinder:grilling
Status: resolved
Assignee: codex
Blocked by: 03

## Question

当前币种视图下，搜索与账户条件如何组合，CSV 如何保持币种范围与导出所见一致？现有导出服务没有搜索页入口，本次是否恢复入口？

## Context

现有 CSV 转换和导出服务仍在，但当前搜索页没有发现导出入口；讨论范围时不应把该入口当作已可使用的功能。

## Comments

- 用户确认：搜索交易严格限制为当前币种，不提供全部币种搜索；例如当前为 CNY 时，不显示匹配的 USD 交易。账户管理的局部币种筛选不改变搜索范围。
- 用户确认：多币种首版明确按当前币种导出的规则，但不在本次恢复 CSV 用户入口；导出入口另行实现。

## Answer

- 搜索始终限定设置中的当前币种；关键词、账户、类型、分类和日期条件只在该币种范围内进一步筛选。账户管理的局部筛选不改变搜索币种。
- 若后续提供搜索结果 CSV 导出，导出当前币种下实际筛选到的记录，保留每行币种代码，不混合其他币种；导出入口不属于本次多币种首版。
