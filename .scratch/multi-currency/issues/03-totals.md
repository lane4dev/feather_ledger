# 多币种金额如何汇总与展示
Type: grilling
Label: wayfinder:grilling
Status: resolved
Assignee: codex
Blocked by: 01, 02

## Question

同一账本同时有 CNY 和 USD 时，以当前币种筛选账本后，如何统一余额、每日小计与月度头部的范围，并处理当前币种切换、初始值、重启与空状态？

## Context

用户要求将上轮提出的方案写入地图：当前币种下只看该币种的交易与账户；账户管理可通过筛选显示其他币种账户。全币种账户管理视图不能混加金额。

已归档及排除合计规则、搜索与导出、账单通知、表单切换和异步更新分别在关联票据中讨论；本票不预先决定这些问题。

## Comments

- 用户确认：只有设置中的一个币种修改入口，视图随设置改变；首次默认根据系统语言，无法判断则使用 USD；重新打开应用以设置中的币种为准，不存在临时切换账本币种。
- 用户确认：当前币种有账户但没有交易时，保留该币种的余额、零收支以及带币种名称的空状态。
- 用户确认：当前币种没有账户而其他币种存在账户时，显示当前币种和零合计，并提示创建该币种的账户；不自动切换到已有账户币种。

## Answer

- 设置是唯一的币种修改入口。当前币种就是设置中选择的币种；更改设置后，账本视图随之切换。没有独立的临时账本币种选择。
- 尚未设置币种时，根据系统语言确定初始币种；无法判断时使用 USD。以后以用户在设置中的选择为准，重新打开应用时继续使用该设置，不因其他币种存在账户而自动切换。系统语言到币种的具体映射由[首次使用时如何确定初始币种](15-initial-currency.md)单独确定。
- 账本的交易、账户、余额和收支合计按当前币种限定；不会将其他币种的金额相加或当成已换算金额。
- 当前币种有账户但没有交易时，保留该币种的余额、零收支和带币种名称的空状态。
- 当前币种没有账户而其他币种有账户时，显示当前币种和零合计，提示创建该币种账户；不自动切换。
- 账户管理可以通过筛选查看其他币种；这个例外只改变账户列表的查看范围，不改变当前币种，也不产生跨币种总额。
- 已归档账户与排除合计账户继续遵循既有规则：归档不自动排除合计；排除合计不隐藏其交易。具体筛选交互由[账户筛选与归档及合计开关如何组合](13-account-filters.md)确定。
