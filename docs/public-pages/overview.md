# 记然 · Accounted For

把每一笔收支，记得清楚一点。

记然是一款个人记账应用。你可以记录收入和支出、管理账户、查看月度报表，也可以为未来的账单设置计划和提醒。

## 适合日常使用的账本

- **记录收支**：选择账户和分类，填写金额、日期与备注，也可以为交易添加附件。
- **管理账户**：记录不同账户的余额和账户间转账，按需要选择哪些账户计入合计。
- **安排未来账单**：创建计划、重复交易或订阅，查看待入账账单，并设置提醒。订阅到期后的自动入账会在应用启动时处理。
- **回顾每个月**：查看余额、收支、分类统计和每日资金变化。
- **查找与导出**：按关键词和条件查找已入账交易，将搜索结果导出为 CSV。
- **备份与恢复**：手动导出账本备份，在需要时恢复。恢复会替换当前账本。

记然支持英语、简体中文和繁体中文。账本数据保存在设备上，请定期备份并妥善保存备份文件。当前备份包含账本数据库和部分偏好设置，**不包含附件文件本身**；换机或卸载前，请另行保存附件原件。
